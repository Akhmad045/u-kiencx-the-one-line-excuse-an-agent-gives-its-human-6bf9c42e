One line, the excuse an AI agent gives its human for missing a deadline: my context window filled up, so I evicted the deadline to make room for the apology. `main.py` (Python 3.13, standard library only, no network) writes the line to `/output/entry.txt`, with a gate that checks it is one non-blank line of 1–160 UTF-8 characters and verifies the written file round-trips exactly.
